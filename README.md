## 1. INTRODUCTION
Crystal Park Gas Solution provides safe, affordable and reliable gas supply and delivery services to households and small business in Crystal Park, Gauteng. The website aims to increase brand awareness, provide product information, and allow customers to submit enquiries online.
## 2. TARGET AUDIENCE
The target audience is households, spaza shops and small restaurants in Crystal Park and surrounding areas. They are looking for affordable gas refills, safety information, and reliable delivery.
## 3. WEBSITE GOALS
1. Inform customers about gas products and pricing
2. Build trust through safety tips and company information
3. Generate leads through the online enquiry form
4. Provide contact details for fast customer support
   ## 4. SITE STRUCTURE-HTML ONLY
   The website consists of 5 interlinked HTML pages: Home, About, Products, Contact, and Enquiry. Navigation is done using anchor tags '<a>' to allow movement between pages. Images are displayed using '<img>' tags.
   ## 5. DESIGN AND TECHNOLOGY -HTML ONLY
   The website is built using pure HTML5. Key elements include '<header>','<nav>','<main>','<footer>','<h1>-<h3>','<p>','<img>','<table>','<form>'. No CSS or JavaScript is used. Images are stored in an 'images/' folder.
